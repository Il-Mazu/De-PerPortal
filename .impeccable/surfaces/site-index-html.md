# Landing page (GitHub Pages)

Scope: public landing page for Dè PerPortal at site/index.html, served by GitHub Pages. Mode: Persuade.
Audience: Skylanders fans playing on Cemu (couch co-op, often with kids) and developers curious how it drives Cemu. Action: download the Windows ZIP from the latest GitHub release; secondary: open the source.
Proof: the real app's screenshots, the real posters, real shortcuts and controller flow, the real SHA-256 of the supported Cemu build, honest beta/untested labels. No invented numbers, testimonials or press.

## Direction contract

THESIS: Dè PerPortal is sold like a Skylanders Starter Pack. The front of the box sells it, the back explains it. Refuses the split hero with a screenshot and three feature cards.

OWN-WORLD: The app's Dusk over Skylands world printed on box card: lapis ground (#0b1446 to #1d2470) with sunburst rays, gilt foil rims (#fff1b8 / #f6c64f / #9a6415), parchment (#f7e6bd) small print, the ten element colours and sigils as the only other colour. Lilita One for everything printed big, Nunito for body. Die-cut plastic window, platform stripe, ribbon, "includes" strip, rating box, barcode.

STORY: Visitors see the box, play with the portal in its window (click, number keys, or a controller held at L3 + R3), download. Scrolling turns the box over, and the back continues as one long gilt-rimmed back panel that shows what it does, how saves stay safe, the six games, thirteen themes, how it is built, how to set it up.

FIRST VIEWPORT: One landscape starter-pack box fills the viewport on a dusk sky. Top-left: platform stripe and logo. Right two thirds: the die-cut window holding the live stone portal, two figure bases (Player 1, Player 2) and the ten-coin dial. Left: headline, 20-word subtext, Download for Windows (gilt) and Source on GitHub. Bottom: an includes strip. Primary action on the box, left, above the fold.

FORM: Toy box (blister/starter pack), candidate 7 of 7, dealt lead. Seed key 189d7882. Signature interaction: the live portal and dial (mouse, keys, Gamepad API). Motion grammar (raised for the user's "full of animation" request): one load sequence (box unboxes, copy rises, coins pop), the box flips over on scroll, figures drop onto the portal with a light burst, backups cycle while in view, Collection slots light up once; nothing loops forever except the drifting sky.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
