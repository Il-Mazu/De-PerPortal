# Skylander list posters

Activision's "collect them all" character posters, one per game, named by game number: 1 Spyro's Adventure, 2 Giants, 3 Swap Force, 4 Trap Team, 5 SuperChargers, 6 Imaginators. They were supplied by the maintainer as scans/photos of the posters and converted to JPEG. Artwork remains © Activision Publishing, Inc.; it is not covered by this repository's code license.

Spyro's Adventure and Imaginators are low-resolution copies (474 px wide); replace them with sharper scans when available. A missing file shows a "no poster" message in the app.
