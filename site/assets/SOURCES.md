# Site assets

Everything here comes from the app; nothing was generated.

- `logo.webp`, `icon.png`, `favicon.png`: the Dè PerPortal logo from `app/ui/`, built on Activision's Skylanders wordmark and element emblems.
- `og.jpg`: the logo over a lapis gradient, made with ImageMagick for link previews.
- `portal.webp`, `portals/`: Activision portal artwork from `app/ui/portal.png` and `app/ui/portals/`. `ring-mask.png` is the portal's light ring cut out of `portal.png` so the page can tint it.
- `sigils.png`: element symbols from Activision's manuals, see `app/ui/icons/SOURCES.md`.
- `posters/`: Activision's character posters, see `app/ui/posters/SOURCES.md`.
- `themes/`: screenshots of the app in each theme.
- `dusk-clouds.webp`: CC0 sky texture by Screaming Brain Studios, see `app/ui/textures/SOURCES.md`.
- `fonts/`: Lilita One and Nunito, SIL Open Font License (`fonts/OFL.txt`).
- `phosphor/`: Phosphor Icons (bold), MIT license (`phosphor/LICENSE`).

Skylanders artwork © Activision Publishing, Inc. It is not covered by the code license. Dè PerPortal is an unofficial fan project.
